## Política de Dados para IA
# Objetivo
Definir requisitos para coleta, armazenamento, processamento e descarte de dados utilizados por sistemas de IA.

# Diretrizes
Coleta
Utilizar fontes autorizadas
Garantir base legal aplicável
Documentar origem dos dados

# Armazenamento
Aplicar controles de segurança
Definir responsáveis pelos dados

# Uso
Garantir finalidade legítima
Evitar uso indevido

# Descarte
Aplicar retenção definida
Eliminar dados quando necessário

# Responsabilidades
# Proprietário dos Dados
Aprovar utilização

# Equipe de IA
Garantir conformidade

# Segurança da Informação
Aplicar controles de proteção
