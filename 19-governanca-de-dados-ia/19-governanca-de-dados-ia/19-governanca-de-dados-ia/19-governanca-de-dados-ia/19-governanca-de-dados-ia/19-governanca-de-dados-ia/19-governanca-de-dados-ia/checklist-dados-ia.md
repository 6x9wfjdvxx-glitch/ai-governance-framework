## Checklist de Governança de Dados para IA

# Origem
-Fonte identificada
- Base legal validada

# Segurança
- Controle de acesso
- Criptografia aplicada

# Qualidade
- Dados revisados
- Dados completos
- Dados atualizados

# Conformidade
- LGPD avaliada
- Consentimento documentado quando aplicável

# Auditoria
- Evidências armazenadas
- Inventário atualizado
