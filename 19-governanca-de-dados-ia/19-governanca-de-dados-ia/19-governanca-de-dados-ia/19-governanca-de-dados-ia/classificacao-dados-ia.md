## Classificação de Dados para IA

# Classificação	Descrição
- Público	Dados sem restrições
- Interno	Uso interno da organização
- Confidencial	Dados sensíveis ao negócio
- Restrito	Alto impacto em caso de exposição

# Exemplos
# Público

- Conteúdo institucional

# Interno
- Procedimentos corporativos

# Confidencial
- Dados financeiros

# Restrito
- Dados pessoais
- Dados regulados
- Segredos comerciais
