## IA Responsável

# Princípios

# Transparência

Os usuários devem saber quando estão interagindo com sistemas de IA.

# Justiça
Modelos devem minimizar vieses e discriminação.

# Segurança
A informação deve ser protegida contra uso indevido.

# Privacidade
O tratamento de dados deve respeitar a LGPD.

# Supervisão Humana
Decisões críticas devem possuir validação humana.
