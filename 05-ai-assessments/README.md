## Avaliações de IA

# Objetivo

Avaliar riscos, controles e requisitos legais antes da implementação de sistemas de IA.

# Critérios de Avaliação

# Segurança

- Controle de acesso
- Registro de atividades
- Proteção de dados

# Privacidade

- Dados pessoais envolvidos
- Base legal
- Direitos dos titulares

# Compliance

- Regulamentações aplicáveis
- Políticas internas

# Ética

- Transparência
- Viés
- Supervisão humana

# Aprovação

A implementação deve ocorrer somente após aprovação da área responsável.

# Referências
- ISO 42001
- NIST AI RMF
- LGPD
