## Prontidão para Certificação ISO 42001

# Objetivo

Avaliar o nível de preparação da organização para uma futura certificação ISO/IEC 42001.

# Checklist

# Contexto Organizacional
- Partes interessadas identificadas
- Escopo definido
- Objetivos documentados

# Liderança

- Política aprovada
- Papéis definidos
- Recursos disponibilizados

# Planejamento

- Avaliação de riscos realizada
- Plano de tratamento criado

# Operação

- Inventário atualizado
- Controles implementados
- Monitoramento realizado

# Avaliação de Desempenho

- KPIs definidos
- Auditorias realizadas

# Melhoria

- Ações corretivas registradas
- Revisões realizadas

# Nível de Maturidade

Nível	Descrição
- 1	Inicial
- 2	Básico
- 3	Definido
- 4	Gerenciado
- 5	Otimizado

# Evidências Esperadas

- Políticas
- Procedimentos
- Relatórios
- Auditorias
- Avaliações de risco
- Registros de treinamento

# Referências
- ISO/IEC 42001
- ISO 31000
- ISO 27001
