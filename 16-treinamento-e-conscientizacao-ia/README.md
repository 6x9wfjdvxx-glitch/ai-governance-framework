## Programa de Treinamento e Conscientização em IA

# Objetivo

# Garantir que colaboradores, gestores e terceiros compreendam:

- Uso responsável da IA
- Riscos associados
- Requisitos regulatórios
- Política corporativa de IA
- Responsabilidades individuais

# Público-Alvo

# Todos os Colaboradores
# Treinamento básico sobre:

- O que é IA
- Uso seguro
- Privacidade
- LGPD
- Boas práticas

# Gestores

# Treinamento adicional:

- Aprovação de sistemas de IA
- Gestão de riscos
- Monitoramento

# Times Técnicos

# Treinamento avançado:

- Desenvolvimento responsável
- Viés algorítmico
- Segurança
- Explainability

# Frequência

- Público	Frequência

- Gestores	Anual
- Equipe Técnica	Semestral

# Evidências

- Certificados
- Lista de presença
- LMS
- Registros de treinamento
