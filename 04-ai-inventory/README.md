## Inventário de Sistemas de Inteligência Artificial

# Objetivo

Manter um registro centralizado de todas as soluções de IA utilizadas pela organização.

# Informações Mínimas

- Nome da solução
- Fabricante
- Área responsável
- Finalidade
- Tipo de IA
- Dados utilizados
- Nível de risco
- Data de avaliação

# Classificação de Risco

# Baixo
Ferramentas sem impacto significativo em clientes ou processos críticos.

# Médio
Ferramentas utilizadas para apoio à tomada de decisão.

# Alto
Ferramentas que influenciam decisões críticas, pessoas ou dados sensíveis.
