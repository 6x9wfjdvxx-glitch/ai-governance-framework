## Plano de Resposta a Incidentes de IA

# Objetivo

Minimizar impactos decorrentes de incidentes envolvendo IA.

# Estratégia

# Contenção
- Isolar sistema afetado
- Suspender processamento quando necessário

# Investigação
- Determinar causa raiz
- Coletar evidências

# Correção
- Ajustar modelo
- Corrigir dados
- Aplicar controles adicionais

# Recuperação
- Restaurar operação normal

# Pós-Incidente
- Revisão
- Lições aprendidas
- Atualização dos controles
